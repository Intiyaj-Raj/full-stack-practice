## 🎯 Features

| Feature                  | Description                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------ |
| 🖼️ **Hero Section**      | Interactive carousel showcasing the learning platform                                      |
| 🛠️ **Services**          | Various development services offered (Web Dev, UI/UX, Frontend, Backend, SEO, Maintenance) |
| 📚 **Courses**           | Three-tier pricing plans (Basic, Standard, Premium)                                        |
| 📝 **Contact Form**      | Full contact form with name, phone, email, address fields                                  |
| 📱 **Responsive Design** | Mobile-friendly with Bootstrap                                                             |

## 🚦 Getting Started

### 📥 Installation

```bash
npm install
```

### 🚀 Development Server

```bash
npm run dev
```

### 📦 Build for Production

```bash
npm run build
```

## 📂 Project Structure

```
src/
├── 📄 App.jsx              # Main app with routing
├── 📄 main.jsx             # Entry point
├── 🎨 App.css              # Global styles
├── 🎨 index.css            # Base styles
├── 🖼️ assets/              # Images and static files
│   ├── 🖼️ 1.jpg, 2.jpg, 3.jpeg
│   └── 📁 services/        # Service images
└── 📁 components/
    ├── 🧭 Navbar.jsx       # Navigation bar
    ├── 🖼️ Hero.jsx         # Hero carousel
    ├── 🛠️ Services.jsx     # Services section
    ├── 📚 Courses.jsx      # Pricing/courses
    ├── 📝 Contact.jsx     # Contact form
    └── 🦶 Footer.jsx       # Footer
```
