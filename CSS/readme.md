# CSS Projects Collection

This folder contains various CSS projects and examples demonstrating different styling techniques, layouts, and interactive effects.

## Projects Overview

### 1. Card Hover Effect (`cardHover/`)

A simple card layout with hover effects showcasing:

- Image cards with descriptions
- Box shadow transitions on hover
- Responsive card design

**Files:**

- `index.html` - HTML structure with two profile cards
- `style.css` - CSS styling with hover animations
- `man.jpeg` & `woman.jpeg` - Profile images

### 2. Tribute Website (`project1/`)

A tribute page for A.P.J. Abdul Kalam featuring:

- Responsive layout design
- Typography hierarchy
- Image styling with circular borders
- Structured content sections

**Files:**

- `index.html` - Complete tribute page structure
- `style.css` - Comprehensive styling for the tribute layout
- `image/apj.jpg` - Portrait image of A.P.J. Abdul Kalam

### 3. CSS Smiley Face (`smileyFace/`)

A pure CSS smiley face demonstrating:

- Shape creation using CSS borders and positioning
- Absolute positioning for facial features
- Color and border-radius properties

**Files:**

- `index.html` - HTML structure for the face elements
- `style.css` - CSS-only smiley face creation

### 4. Job Application Form (`Project 2/`)

A responsive job application form with:

- CSS Grid layout for form controls
- Form styling and validation states
- Hover effects on buttons
- Mobile-responsive design with media queries

**Files:**

- `index.html` - Job application form structure
- `style.css` - Form styling with grid layout and responsive design

## Technologies Used

- HTML5
- CSS3 (including Grid, Flexbox, Transitions, and Media Queries)

## How to View Projects

1. Open any project's `index.html` file in a web browser
2. Each project is self-contained within its folder
3. No additional dependencies required

## Learning Objectives

These projects demonstrate:

- CSS layout techniques (Flexbox, Grid)
- Responsive web design
- CSS animations and transitions
- Form styling
- Image manipulation with CSS
- Pure CSS graphics creation
