This HTML Cheatsheet is For You!
  1. HTML Boilerplate 
    <!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
</body>
</html>
  2. <!DOCTYPE html> – Defines HTML5 document type. 
    <!DOCTYPE html>
  3. <html> – Root element of the page. 
    <html>...</html>
  4. <head> – Contains meta info and links. 
    <head>...</head>
  5. <title> – Page title in browser tab. 
    <title>My Page</title>
  6. <meta> – Page information. 
    <meta charset="UTF-8">
  7. <body> – Visible page content. 
    <body>Content</body>
  8. <h1> to <h6> – Headings. 
    <h1>Main Heading</h1>
  9. <p> – Paragraph text. 
    <p>This is a paragraph.</p>
  10. <br> – Line break. 
    Line 1<br>Line 2
  11. <hr> – Horizontal line. 
    <hr>
  12. <a> – Hyperlink. 
    <a href="#">Click here</a>
  13. <img> – Image display. 
    <img src="image.jpg" alt="image">
  14. <ul> – Unordered list. 
    <ul>
    <li>Item</li>
</ul>
  15. <ol> – Ordered list. 
    <ol>
    <li>Item</li>
</ol>
  16. <li> – List item. 
    <li>Item</li>
  17. <div> – Block container. 
    <div>Content</div>
  18. <span> – Inline container. 
    <span>Text</span>
  19. <table> – Table container. 
    <table>
    <tr>
        <td>Data</td>
    </tr>
</table>
  20. <tr> – Table row. 
    <tr></tr>
  21. <td> – Table data cell. 
    <td>Data</td>
  22. <th> – Table header cell. 
    <th>Header</th>
  23. <form> – Form container. 
    <form>...</form>
  24. <input> – Input field. 
    <input type="text">
  25. <textarea> – Multi-line input. 
    <textarea></textarea>
  26. <button> – Clickable button. 
    <button>Submit</button>
  27. <select> – Dropdown. 
    <select>
    <option>Option</option>
</select>
  28. <label> – Label for input. 
    <label>Name</label>
  29. <header> – Page header. 
    <header>Header</header>
  30. <nav> – Navigation section. 
    <nav>Menu</nav>
  31. <section> – Content section. 
    <section>Content</section>
  32. <article> – Independent content. 
    <article>Post</article>
  33. <aside> – Sidebar. 
    <aside>Sidebar</aside>
  34. <footer> – Page footer. 
    <footer>Footer</footer>
  35. <audio> – Audio player. 
    <audio controls>
    <source src="audio.mp3">
</audio>
  36. <video> – Video player. 
    <video controls>
    <source src="video.mp4">
</video>
  37. <iframe> – Embed another page. 
    <iframe src="https://example.com"></iframe>
  38. <script> – JavaScript code. 
    <script>
alert("Hello");
</script>
  39. <link> – External CSS file. 
    <link rel="stylesheet" href="style.css">
